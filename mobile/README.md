# Aqua Gestão Mobile

Aplicativo Expo para as equipes de saneamento consultarem atendimentos,
registrarem a execução de serviços e anexarem fotos em campo.

## Executar

```sh
cd mobile
npm install
npm start
```

Abra o projeto no Expo Go pelo QR code ou use `npm run android`, `npm run ios`
(em um Mac) ou `npm run web`.

## Acesso demonstrativo

- E-mail: `operador@aquagestao.com.br`
- Senha: `agua2026`

O login e as ordens são demonstrativos e não se conectam à API. Os relatórios e
fotos ficam apenas na memória durante o uso do app; conecte uma API e um serviço
de armazenamento antes de usar em produção.
